This guide will help you complete the setup of the Google Play Integrity API in your app.

## 🔧 Configuration Required

### 1. Get Your Cloud Project Number

1. Go to [Google Cloud Console](https://console.cloud.google.com/)
2. Select your project (the one linked to your Play Console app)
3. Click on **Project Settings** (gear icon in the top navigation)
4. Find your **Project Number** (it's a long number like `123456789012`)

### 2. Update the Cloud Project Number

Open this file:
```
android/app/src/main/kotlin/com/noxquill/rewordium/integrity/PlayIntegrityHandler.kt
```

Find this line (around line 28):
```kotlin
private const val CLOUD_PROJECT_NUMBER = 0L // Replace with your project number
```

Replace `0L` with your actual project number:
```kotlin
private const val CLOUD_PROJECT_NUMBER = 123456789012L // Your actual number
```

### 3. Verify Play Console Setup

Ensure these are configured in [Google Play Console](https://play.google.com/console/):

1. **App Integrity** section:
   - Go to: Release → Setup → App Integrity
   - Verify "Play Integrity API" is enabled
   - Link your Google Cloud project if not already done

2. **Play App Signing**:
   - Go to: Release → Setup → App signing
   - Ensure your app is enrolled in Play App Signing
   - This is required for the Integrity API to work

### 4. Test the Integration

You can test the Play Integrity API with this code in your Dart code:

```dart
import 'package:rewordium/services/play_integrity_service.dart';

// Basic integrity check
Future<void> testIntegrity() async {
  final isValid = await PlayIntegrityService.checkIntegrity();
  print('Integrity check passed: $isValid');
  
  // Get detailed verdict
  final verdict = await PlayIntegrityService.getIntegrityVerdict();
  print('Integrity verdict: $verdict');
  
  // Check device security
  final isSecure = await PlayIntegrityService.isDeviceSecure();
  print('Device is secure: $isSecure');
}
```

### 5. Backend Verification (Recommended)

For production apps, you should verify the integrity token on your backend:

1. The app requests a token from Play Integrity API
2. Send this token to your backend server
3. Your backend calls Google's API to verify the token
4. Backend returns the verdict to your app

**Backend verification endpoint:**
```
POST https://playintegrity.googleapis.com/v1/{packageName}:decodeIntegrityToken
```

See: [Verify Integrity Tokens](https://developer.android.com/google/play/integrity/verdict)

## 📱 How It Works

The Play Integrity API is now integrated and will:

1. **Initialize** when the app starts (in `main.dart`)
2. **Verify app integrity** - Detects if your app has been tampered with
3. **Check device integrity** - Verifies the device meets Play Protect requirements
4. **Validate install source** - Confirms the app was installed from Google Play

## 🔍 Testing

### Local Testing
- The API works in **debug mode** but may return different verdicts
- For accurate testing, use an **internal testing track** in Play Console
- Upload a signed APK/AAB and install from Play Store

### Production
- Only devices with Google Play Services can use this API
- Devices without Play Services will gracefully fail and allow app usage
- Consider device security checks as advisory, not blocking

## 🛠️ Troubleshooting

### Error: "API_NOT_AVAILABLE"
- Device doesn't have Google Play Services
- Update Google Play Services on the device

### Error: "INVALID_REQUEST"
- Check that `CLOUD_PROJECT_NUMBER` is set correctly
- Verify the Cloud project is linked in Play Console

### Error: "NETWORK_ERROR"
- Check internet connection
- Verify Google Play Services is up to date

### No Token Received
- Ensure app is signed with the same keystore registered in Play Console
- Check that Play Integrity API is enabled in Google Cloud Console

## 🔐 Security Best Practices

1. **Always verify tokens on your backend** for critical operations
2. **Don't rely solely on client-side verification**
3. **Use nonces generated by your backend** for each request
4. **Monitor integrity verdicts** to detect abuse patterns
5. **Handle failures gracefully** - Don't block all users if API fails
