What The App Does

Rewordium helps users write faster and better on mobile by combining predictive text, rewrite assistance, and style adaptation into a single keyboard-first flow.

Key Experience Goals

  • Reduce typing effort in high-volume conversations.
  • Improve confidence for non-native or time-constrained writers.
  • Keep interactions minimal, responsive, and privacy-conscious.

Current Stack

Flutter Firebase Cloud Functions Three.js GSAP + ScrollTrigger Vanilla JS Modules

Delivery Priorities

  • Improve screen-to-screen onboarding narrative.
  • Expand multilingual rewrite quality.
  • Tune suggestion ranking with real usage metrics.
