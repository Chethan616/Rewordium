16 KB Memory Page Size Support

This page documents Rewordium's compliance with Google Play's 16 KB memory page size requirement for apps using native code.

Status

Compliance
Fully compliant (NDK r28 + uncompressed JNI libs)
Deadline
Before November 1, 2025 (met)
Supported ABIs
arm64-v8a (primary), backward-compatible with 4 KB pages

Technical Implementation

The Android build is configured to support 16 KB page size devices by:

  • Using NDK 28.0.12433566 (r28) which adds 16 KB compatibility.
  • Setting useLegacyPackaging = false for jniLibs to store native libraries uncompressed and properly aligned.
  • Configuring abiFilters for arm64-v8a and debugSymbolLevel to SYMBOL_TABLE.

Reference files:

  • Android app module: android/app/build.gradle.kts
  • Project documentation: 16KB_MEMORY_PAGE_SIZE_SUPPORT.md

Verification

  • Release builds generated with AGP ≥ 8.5 and NDK r28 produce bundles compatible with 16 KB devices.
  • Native libraries are uncompressed to ensure correct alignment on 16 KB boundaries.
  • Internal testing confirms successful install and run on 4 KB and 16 KB configurations.

No application logic changes are required; this is a build configuration update.
