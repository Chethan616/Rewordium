## 🎯 What's New

### 🎨 Material 3 Tools FAB Redesign
- Redesigned the Tools Floating Action Button (FAB) into a clean, modern Material 3 fan-out menu for quick access to your favorite writing tools.

### 🖼️ Sticker Studio & Animated GIFs
- **Sticker Studio:** Fully unified sticker and GIF panels with clipboard fullscreen overlay and themed card styles.
- Support for animated GIFs, sticker packs, and custom tag filtering to express yourself creatively.
- Cached picked URIs to prevent Android permission denial when adding stickers.

### ⌨️ iOS Keyboard Engine Upgrades
- Upgraded iOS Keyboard Extension target for full Swift 6 and KeyboardKit v10 compatibility.
- Integrated experimental rounded smartbar toggle and fixed transparent window clipping issues.
- Centered all modifier icons and stripped Tab and CapsLock physically from the layout to adhere strictly to Apple HIG principles.

### 🧹 Native Input & Suggestion Optimizations
- Bypassed NavController auto deep-link handling to resolve task recreation crash loops on startup.
- Resolved `CropImageView` infinite measure and reload loop on image loading.
- Faster, smarter suggestions and smoother adaptive theme transitions.
